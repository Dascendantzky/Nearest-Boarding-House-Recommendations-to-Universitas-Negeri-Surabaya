### Nearest-Boarding-House-Recommendations-to-Universitas-Negeri-Surabaya

This dataset dummy information about boarding houses located around Universitas Negeri Surabaya (UNESA), which is used to develop a distance-based recommendation system.

The dataset consists of 91 boarding houses with 10 attributes/features.

📌 Dataset Attributes
Unique Code → Unique identifier for each boarding house
Boarding House Name → Name of the boarding house
Price → Monthly rental cost
Region → Area/location of the boarding house (e.g., Wonocolo, Ketintang, etc.)
Phone Number → Contact number of the owner
Available Rooms → Number of available rooms
Facilities → Available facilities (AC, WiFi, private bathroom, etc.)
Gender Type → Category of tenants (Male, Female, or Mixed)
Distance to UNESA → Distance from the boarding house to UNESA (in kilometers)
Photo → Image file path of the boarding house
🎯 Purpose

This dataset is used to:

Analyze the distribution of boarding houses around UNESA
Develop a boarding house recommendation system based on proximity
Help students find suitable housing based on preferences such as price, facilities, and distance
